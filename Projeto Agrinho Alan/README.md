# Projeto Agrinho: Sustentabilidade no Campo e na Cidade

Este é um projeto de site básico desenvolvido para a disciplina de **Educação Digital**, com o objetivo de explicar conceitos fundamentais de sustentabilidade, como a importância da preservação ambiental e o uso dos pilares dos 3 Rs (Reduzir, Reutilizar e Reciclar).

## 🚀 Tecnologias Utilizadas

O site foi construído do zero utilizando as três tecnologias base da internet:
- **HTML5:** Para a estruturação de textos, seções e imagens do site.
- **CSS3:** Para a estilização visual, definição de cores (paleta verde/sustentável) e responsividade.
- **JavaScript:** Para a interatividade do site, contendo uma função que sorteia dicas ecológicas para o usuário.
